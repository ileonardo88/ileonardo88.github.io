# Fotografías de los previews capilares

Archivo: `atlas.png`. Creado con la herramienta integrada de generación de imágenes, para estos tres previews. Marca, envases y productos ficticios.

Prompt utilizado: atlas fotográfico de cuatro columnas por dos filas, ocho celdas cuadradas sin márgenes. Primera fila: campaña profesional con mujer adulta de cabello oscuro brillante y botellas violetas; retrato cálido de mujer adulta con rizos; retrato de cabello castaño ondulado; retrato de cabello afro. Segunda fila: shampoo violeta, acondicionador marfil, protector térmico ámbar y mascarilla ciruela. Marca ficticia MELENA, fotografías de estudio realistas, productos completos con margen, sin marcas reales, promesas de resultados ni interfaces dibujadas. Paletas violeta, crema, ámbar y rosa. El CSS selecciona cada celda sin modificar el archivo original.

Los previews son páginas React interactivas. Los filtros, favoritos, bolsa y rutinas usan datos de muestra en memoria; no procesan pedidos ni pagos.
